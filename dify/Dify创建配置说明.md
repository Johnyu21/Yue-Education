# Dify 工作室配置

1. 使用Dify1.12.1，在现有应用中先导出DSL备份。
2. 画布空白处右键→导入DSL→选择对应YML→覆盖草稿。现有应用API Key保持可用。
3. 核对LLM模型和工作室供应商凭据，保留当前deepseek-v4-flash。
4. 客服、学生当前绑定对外知识库，企业绑定内部知识库。学生新增专用库后在“在工作室选择对应知识库”节点切换；核对文档范围、索引状态和检索参数，不要让学生绑定员工专用库。
5. 点击发布→发布更新。更换工作空间时重新选库。
6. 将服务API地址和六个应用Key交给项目维护者配置backend/.env，然后重启后端。
7. 在项目悬浮窗验证知识引用、缺项追问和确认办理。Dify自身不直接写业务数据。

不需要修改知识库UUID配置，不需要运行生成脚本。详见[接入与验收记录](../docs/Dify1.12.1工作流优化与知识库接入说明.md)。
