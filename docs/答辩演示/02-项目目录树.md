> 生成日期：2026-10-19
> 用途：答辩时快速说明「代码放在哪里、每个目录负责什么」
> 说明：已省略 `node_modules/`、`.venv/`、`__pycache__/`、`*.pyc`、`.git/` 等生成物。

## 一、整体结构

```
Yue-Education/
├─ README.md                     项目总说明、快速启动、文档导航
├─ 一键启动.cmd                  Windows 一键启动（建环境→装依赖→起前后端）
├─ 一键停止.cmd                  停止前后端进程
├─ 一键准备环境.cmd              仅准备 Python/Node 环境
│
├─ backend/                      后端：Python 3.12 + FastAPI + SQLAlchemy + PostgreSQL
├─ frontend/                     前端：Vue 3 + TypeScript + Vite
├─ dify/                         Dify 工作流 DSL 与接入说明
├─ deploy/                       建表脚本与容器部署物料
├─ tools/                        环境准备、启动器、Dify 构建与联调工具
└─ docs/                         需求、契约、交付与演示文档
```

## 八、答辩时的「一句话定位」

| 目录 | 一句话说明 |
|---|---|
| `backend/app/controllers` | 接口入口，按业务资源分文件 |
| `backend/app/services` | 真正的业务规则：状态机、事务、权限、AI 编排 |
| `backend/app/core/permissions.py` | 数据范围在这里收敛成 SQL 条件 |
| `backend/app/integrations/dify` | AI 的唯一出口，密钥只在后端 |
| `frontend/src/App.vue` | 前端单壳：访客 / 登录 / 工作台三态 |
| `frontend/src/components/BusinessWorkspace.vue` | 通用业务工作台，按契约渲染 |
| `frontend/src/api/resources.ts` | 页面能做什么、权限门禁都在这里 |
| `dify/*.yml` | 可导入 Dify 的工作流 DSL |
| `deploy/schema.sql` + `migrations/` | 数据库结构与增量迁移 |
