## 二、设计说明

### 2.1 为什么文件名要重新生成 ⭐

**问题（路径穿越攻击）**：
```
用户上传文件，文件名填 "../../../../etc/passwd"
如果直接用这个名拼路径 → 覆盖了系统文件
```

**所以**：
1. 文件名**重新生成**（`secrets.token_hex(16)`，**不用用户给的**）
2. **只认扩展名**，且在白名单内
3. 存完后 `resolve()` 再检查是否还在存储根目录内（**双保险**）

**验证过**：
```
✅ 上传文件名 "../../../evil.pdf"
   → 实际存为 "u/12/a1b2c3d4....pdf"（用户名被丢掉）
✅ resolve_path("../../../../etc/passwd") → None（拒绝）
```

### 2.2 为什么按 owner 分目录（防"伪造归属"）

**问题**：如果所有文件都存一个目录，A 可能**上传到 B 的目录**，
或者**覆盖 B 的文件**。

**所以**：按 `u/{owner_user_id}/` 分目录。
**owner 来自登录身份，不来自客户端** —— 无法伪造。

### 2.3 为什么限制类型和大小

| 限制 | 防什么 |
|---|---|
| **扩展名白名单** | `.php`/`.exe` 等危险文件 |
| **MIME 校验** | `.pdf` 里其实是脚本（伪装） |
| **10MB 上限** | 占满磁盘（DoS） |

**边读边写边计数** —— 一旦超限，**立刻停止并删掉写了一半的文件**（不留残file）。

**验证过**：
```
✅ test_拒绝危险扩展名（.php/.exe/无扩展名）
✅ test_超大文件被拦（且不留残file）
```

### 2.4 为什么"私有存储 + 短期下载"

**问题**：如果文件存放在静态目录（如 `/static/uploads/`），
**任何人知道 URL 就能下载别人的简历** —— 严重泄露。

**所以**：
- 文件**不放在静态目录**
- 数据库只存 `object_key`
- **下载走鉴权接口**（校验是不是本人的）

### 2.5 为什么数据库只存 `object_key` 不存路径

**问题**：如果存绝对路径（`/Users/xxx/storage/u/12/a.pdf`），
**换台机器就失效** —— 违反 M1-10"不依赖个人机器路径"。

**所以**：存**相对标识**（`u/12/a1b2c3.pdf`），
实际根目录由 `file_storage_root` 配置决定。

## 四、使用方式

### 4.1 上传

```python
from fastapi import File, UploadFile
from app.core import storage

@router.post("/api/v1/files")
def upload_file(file: UploadFile = File(...),
                user: SysUser = Depends(require_password_changed)):
    object_key = storage.save_upload(file, owner_user_id=user.id)
    # ⚠️ 返回 object_key，不返回真实路径
    return ok({"objectKey": object_key, "filename": file.filename})
```

### 4.2 存到业务表

```python
# 简历：crm_lead.resume_object_key
lead.resume_object_key = object_key
```

### 4.3 下载（带鉴权）

```python
from app.core.storage import resolve_path
from fastapi.responses import FileResponse

@router.get("/api/v1/files/{key}")
def download(key: str, user: SysUser = Depends(require_password_changed)):
    # ⚠️ 1. 先查这个 key 是不是属于当前用户（或用户有权看）
    #    2. 再解析路径（内部有穿越检查）
    path = resolve_path(key)
    if path is None:
        raise NotFoundError("文件不存在")
    return FileResponse(path)
```

### 4.4 允许的类型

```
.pdf  .jpg  .jpeg  .png  .doc  .docx  .xls  .xlsx
```
**单文件上限：10MB**

## 五、注意事项

| ❌ 不要 | 为什么 | ✅ 应该 |
|---|---|---|
| 用用户给的文件名存盘 | **路径穿越漏洞** | 用 `storage.save_upload`（自动重命名） |
| 把文件放静态目录 | 谁都能下载别人的文件 | 私有存储 + 鉴权下载 |
| 存绝对路径到数据库 | 换机器就失效 | 存 `object_key`（相对） |
| 一次读进内存再判断大小 | 大文件撑爆内存 | `save_upload` 已边读边计数 |
| 只查扩展名不查 MIME | 伪装扩展名能绕过 | 两个都查（已实现） |
| 下载不做归属校验 | 改个 key 就能下别人的 | 先查归属再给文件 |

### ⚠️ 一个连带的依赖

**`UploadFile` 需要 `python-multipart`** —— 已加进 `requirements.txt`。
