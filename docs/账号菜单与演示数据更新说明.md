# 账号菜单与演示数据更新说明

日期：2026-10-17。

## 页面调整

右上角个人设置下拉包含个人资料、修改密码、账号与附件、退出登录；系统管理员额外看到账号管理。下拉支持点击外部与Escape关闭，进入其他页面时自动收起。

通知铃铛展开最近6条通知，显示未读数量。选择某条消息后标记已读，并进入通知中心自动选中该条消息的详情。列表可查看全部通知。

个人资料显示当前登录人的姓名、本人登录账号、岗位、部门及联系方式；学生补充显示班级、顾问、城市和学历。现有后端未提供普通用户修改本人资料的通用接口，因此本轮提供真实资料查看及改密入口，资料维护仍由管理员处理。

新增独立系统账号管理页面，仅管理员可访问。支持查看员工/管理员及学生列表、搜索、维护员工账号配置、重置各类账号密码；学生通过档案中的实际userId定位，避免误把学生档案编号当作账号编号。停用或未出现在目录中的账号可输入已核实的用户编号后确认重置。重置本人密码时先保留临时密码显示，关闭结果后退出登录。

非管理员的员工通讯录列表、详情及账号维护表单均隐藏登录账号，管理员保留显示。经用户追加批准，通讯录接口也只在管理员响应中返回username，普通员工响应完全省略该字段。

## 本轮获准的后端修改

用户批准扩大管理员密码重置范围，因此仅在现有组织控制器和服务中将原学生限制扩大到所有用户账号；保留仅管理员可调用、随机临时密码、7天有效期、强制首次改密和旧令牌失效规则，并给目标用户加行锁。用户另行批准通讯录响应的username按管理员权限过滤，控制器仅增加条件字段输出。无数据库结构变更。同步更新OpenAPI说明与前端契约快照。

## 演示数据

演示环境初始化7名学生、2名顾问、2名班主任及对应班级、项目、成绩、日程、通知。详见演示账号与数据说明.md。通过frontend/scripts/backend-qa-server.py在专用 *_test 库随机schema中创建，不向正式库插入合成资料。
