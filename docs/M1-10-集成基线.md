## 二、设计说明

### 2.1 为什么需要这份文档

**问题**：新人 clone 代码后，会卡在这些地方——
- 数据库怎么起？（不知道 `deploy/` 里有 compose）
- 没有账号怎么登录？（不知道要跑种子）
- 缺依赖报错？（不知道要 `pip install`）
- 某台机器能跑、另一台不行？（路径写死了）

**所以**：把"从零到能登录"的每一步写清楚，**任何人在任何机器上照着做都能成功**。

### 2.2 为什么种子脚本要"幂等"

**问题**：新人可能跑两次种子（比如第一次失败想重试）。
如果每次都插入，会**报"用户名已存在"**，卡住。

**所以**：**已存在的跳过**（每步先查再插）。**重复跑安全**。

### 2.3 为什么配置要按 02 文档补全

**问题**：02 文档列了完整的环境变量清单（Dify 四把 key、业务时区、
SLA 阈值等）。**我们一开始只写了数据库和 JWT** ——
等 M2/M3 接 Dify 时才发现**没有 key 可配**，要回头改。

**所以**：**现在补齐**，把清单一次列全（值可以先空着）。

### 2.4 为什么不依赖个人机器路径

**问题**：如果代码里写死 `/Users/xxx/project/...`，
换台机器就崩。

**所以**：
- 文件存储用**相对路径**（`./storage`，可配置覆盖）
- 数据库连接从 `.env` 读
- **没有绝对的本地路径**

## 四、使用方式（新人照做）

### 第 0 步：确认前提

```bash
docker --version && docker compose version    # 有输出就行
python3 --version                             # 3.11+
```

### 第 1 步：拿代码

```bash
git clone http://47.106.207.27:3000/wolin_jiangsai/Yue-Education.git
cd Yue-Education
```

### 第 2 步：起数据库（建好 19 张表）

```bash
cd deploy
docker compose up -d

# 验证（应输出 19）
docker exec edu-pg psql -U postgres -d education -t -c \
  "SELECT count(*) FROM information_schema.tables WHERE table_schema='public';"
```

### 第 3 步：配后端

```bash
cd ../backend
cp .env.example .env          # 开发用默认值即可，不用改
```

### 第 4 步：装依赖 + 起服务

```bash
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt

uvicorn app.main:app --reload --port 8000
```

### 第 5 步：灌种子数据（**另开一个终端**）

```bash
cd backend && source .venv/bin/activate
python -m scripts.seed
```

**它会打印测试账号**：

### 第 6 步：登录验证 ✅

## 六、注意事项

| ❌ 不要 | 为什么 | ✅ 应该 |
|---|---|---|
| 忘了跑种子脚本 | 没有账号 → 登录不了 | 第 5 步必做 |
| 忘了 `pip install` | 报 `ModuleNotFoundError` | 第 4 步必做 |
| 用系统 Python 装依赖 | 污染环境，且可能版本冲突 | **一定要激活 venv** |
| 端口 8000 被占 | 起不来 | 换端口 `--port 8001` |
| 改了 `.env` 却没重启 | 配置不生效 | 改完重启服务 |
| 把 `.env` 提交到 git | 泄露密码 | 已在 `.gitignore` 排除 |
| 跳过 `.venv` 直接 `pip install` | 装到系统里 | 先 `source .venv/bin/activate` |

### ⚠️ Windows 用户的三个坑

1. **激活虚拟环境**：`.venv\Scripts\activate`（不是 `source`）
2. **Docker Desktop 要先启动**（不是装了就行）
3. **WSL2**：Docker Desktop 安装时会引导开启

### ⚠️ 排障：起不来先看这里

| 现象 | 原因 | 解决 |
|---|---|---|
| `Connection refused`（连数据库） | 数据库没起 | `cd deploy && docker compose up -d` |
| `database:false` | 同上 | 检查 `docker compose ps` |
| 登录返回"用户名或密码错误" | 没跑种子 | `python -m scripts.seed` |
| `ModuleNotFoundError: multipart` | 依赖没装全 | `pip install -r requirements.txt` |
| 表存在但查询报错 | 结构是旧版 | `docker compose down -v && up -d` |
