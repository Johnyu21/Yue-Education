# 访客页面动效与视频更新说明

日期：2026-10-17。本轮仅修改前端，未修改后端接口、权限或业务逻辑。

## 首页视频引导

首页展开的宣传视频中央新增服务文案及“了解留学项目”“进入服务系统”两个按钮，分别定位到项目介绍、进入正式登录页面。保留原有声音开关、播放暂停与收起按钮。视频默认静音循环；每次打开或刷新首页展开，站内返回首页保持收起，仍可手动展开。

## 访客动画

项目、政策、项目详情、政策详情、关于我们和活动页面统一使用滚动触发的左右交错入场。采用原生IntersectionObserver观察可视范围，异步加载的公开项目及活动内容通过MutationObserver纳入；离开页面时清理观察器及事件。卡片增加悬停抬升，链接和按钮增加点击波纹、轻微按压反馈，费用和常见问题展开时淡入。图片轮播增加交叉渐变与轻微位移。顶部细线显示浏览进度，滚动事件使用被动监听与requestAnimationFrame合并更新。

动效不会阻止表单或链接的正常操作，不隐藏无法被观察的页面内容；键盘聚焦会显示所在内容。系统开启“减少动态效果”时，内容直接显示，关闭主要位移、波纹及轮播过渡。

## 登录视频

登录页左侧使用现有宣传视频素材，静音循环播放，增加虚化和深色渐变遮罩，保留原有文字及右侧登录表单。提供暂停/播放按钮；标签页隐藏时暂停，返回后按用户选择继续播放；系统要求减少动态效果时默认暂停。播放失败时保留原有底色和文字。

## 修改位置

- frontend/src/VisitorPromoVideo.vue：视频中央引导。
- frontend/src/visitorMotion.ts、visitor-motion.css：滚动、点击、进度及卡片动效。
- frontend/src/VisitorPages.vue：各访客页面接入动效。
- frontend/src/VisitorGallery.vue：轮播过渡。
- frontend/src/components/LoginVideoBackdrop.vue：登录背景视频和播放控制。
- frontend/src/App.vue、business.css：登录页接入和文字层级。
