# 海外生活指南（学生知识库 · 生活支持）

> 用途：上传至 Dify 工作室"学生助手"绑定的知识库，支撑学生助手"生活支持"场景问答（医疗、交通、紧急求助、日常生活）。
> 说明：以下为通用安全常识，机构 Specific 的保险、接机、住宿安排请按实际情况在对应小节补充后再发布。

## 一、紧急求助

- 全欧盟统一紧急电话：112（报警/急救/消防通用，免费，可要求中文翻译服务）。
- 美国：911；英国：999（非紧急报警 101）；澳大利亚：000；日本：110（报警）/119（急救火警）。
- 中国驻外使领馆领保电话：请提前保存所在国家使领馆的 24 小时领事保护电话；外交部全球领保热线 +86-10-12308。
- 紧急情况先确保自身安全，再拨打当地紧急电话；需要警方笔录或医院证明时保留原件，用于保险理赔和向学校报备。

## 二、医疗就医

- 小病优先选择社区诊所（Clinic / Hausarzt / GP），大医院急诊（Emergency / ER / A&E）用于高热不退、外伤出血、呼吸困难等急症。
- 就诊需携带：护照/身份证件、保险卡、既往病历或用药清单；非英语国家可提前准备症状翻译短语或使用翻译软件。
- 购买处方药需医生处方；药店（Pharmacy / Apotheke / Chemist）药剂师可提供非处方药建议。
- 看病后保留诊断证明和费用单据，按保险公司要求提交理赔；建议抵达后一周内确认医疗保险生效日期和覆盖范围。
- 心理支持：多数学校提供免费心理咨询服务（Student Counseling），可在学校官网或学生服务中心预约；情况紧急时同样拨打当地紧急电话。

## 三、交通出行

- 下载当地公共交通 App 并绑定交通卡（如德国 Deutschlandticket、英国 Oyster、日本 Suica），学生通常可购买折扣票。
- 乘坐公交地铁注意末班车时间；夜间出行尽量结伴或使用正规网约车/出租车平台。
- 骑自行车需遵守当地交规（夜间开灯、专用车道）；部分国家骑车必须购买自行车保险并注册。
- 长途出行提前购票；跨境旅行确保护照、签证/居留许可有效期充足。

## 四、住宿与生活

- 入住后第一时间确认：水电网开通、门锁钥匙、火灾逃生通道、垃圾分类规则。
- 保管好租房合同和押金凭证；退租提前按合同通知期书面通知房东。
- 办理当地手机卡需护照实名登记；银行开户建议选择学生账户，开通网上银行并保存客服电话。
- 防范诈骗：不向陌生电话透露验证码；"使馆来电""快递扣押""换汇优惠"均为常见诈骗手法，遇到可疑电话先挂断并向学校或使馆核实。

## 五、常用求助渠道

| 事项 | 渠道 |
| --- | --- |
| 生命危险/治安事件 | 当地紧急电话（112 / 911 等） |
| 护照丢失 | 联系中国驻当地使领馆补办，同时向当地警方报备 |
| 学业或生活困难 | 联系本机构班主任、顾问，或学校学生服务中心 |
| 保险理赔 | 保险公司 24 小时客服（见保险卡背面） |
