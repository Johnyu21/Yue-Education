# 研判准入规则参考（建议值，需业务负责人审核后再录入）

> 依据《用户画像研判规则》整理。录入到「留学项目 → 维护与发布项目 → 准入规则」，
> 保存后规则处于「未审核」状态（rule_approved_at 为空），判定会返回 NEEDS_INFO；
> 由业务负责人审核通过后才生效。字段枚举与研判提取的 16 字段一致。

## 一、中德精英人才共建计划（德国双元制）

```json
{
  "version": "v1",
  "criteria": [
    {"field": "age", "op": "GTE_NUM", "value": 18, "label": "年龄≥18岁"},
    {"field": "age", "op": "LTE", "value": 35, "label": "年龄≤35岁"},
    {"field": "education", "op": "IN", "values": ["高中","中职","职高","中专","技校","专科","本科"], "label": "高中及以上学历"},
    {"field": "criminal_record", "op": "EQ", "value": "无", "label": "无犯罪记录"},
    {"field": "german_potential", "op": "IN", "values": ["有基础","可学"], "label": "具备德语学习能力"}
  ],
  "scoring": [
    {"field": "handson_ability", "weights": {"强": 20, "中": 10}},
    {"field": "logic_thinking", "weights": {"强": 20, "中": 10}},
    {"field": "german_potential", "weights": {"有基础": 20, "可学": 10}},
    {"field": "family_economy", "weights": {"富裕": 20, "中等": 15, "一般": 5}}
  ]
}
```

说明：`criminal_record=未提及` 会被判 NO_MATCH（无法证明无犯罪记录），缺失则 NEEDS_INFO。

## 三、录入与生效步骤

1. 项目管理 → 对应项目 → 维护与发布项目 → 准入规则（粘贴上面的 criteria/scoring JSON）。
2. 保存后默认「未审核」，系统自动返回 NEEDS_INFO；审核通过后才会真正判定 MATCH/NO_MATCH 并给分。
3. 年龄类硬筛用 `GTE_NUM/LTE`，枚举类用 `EQ/IN`，缺失自动判 NEEDS_INFO，不会误判。
