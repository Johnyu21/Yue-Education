### 2.3 修复的既有缺陷（阻塞 M2 核心路径）

```python
# models/lead.py（改前）
dept_id: Mapped[int] = mapped_column(BigInteger)   # 非空，但 DDL 里 crm_lead.dept_id 本就可空
```
DDL 中 `crm_lead.dept_id` 可空（"未路由时可空，进管理员待分配池"），模型却标成非空 →
**项目没有默认部门时留资直接落库失败**。已改为 `Mapped[int | None]`，并新增用例覆盖。

## 三、关键设计取舍（与 04 文档的偏差，均已落地并注明理由）

| # | 取舍 | 理由 |
|---|---|---|
| 1 | **响应字段统一 camelCase**（分页 `{items,page,pageSize,total}`） | M1 的 `auth.py` 与 M4 全部接口已是 camelCase，实现层已事实修订设计文档；M5 只需一套映射 |
| 2 | **附件只校验 `object_key` 归属**（前缀 `u/{actor_id}/` + 文件存在），`upload_proof` 可选 | M1 的 API028 只返回 `{objectKey, filename}`，并不存在 04 文档要求的 `upload_proof`；保留字段以便 M1 后续补齐 |
| 3 | **访客侧不使用 M1 confirmation 令牌**，改用"服务端签发 requestKey + `confirmed=true`" | 令牌绑定登录 actor，访客无账号；且公开留资/报名本身无越权空间 |
| 4 | **打分口径收紧**：只要存在 `NEEDS_INFO` 就不给 `latestScore` | 避免"信息不全却给出貌似精确的分数"（M2 文档明确禁止） |
| 5 | **AI 提取结果不参与规则判定** | 参与判定的只有"已确认事实"（客户主档事实 ∪ 本次 `confirmed_facts`）；提取结果作为参考材料放进报告 `extraction` |
| 6 | **`isPreviousReport`**：状态为 FAILED 且仍留有报告时为 true | 失败保留上一份成功报告，前端据此标注"历史报告" |
| 7 | 限流与会话草稿为**进程内**实现 | 依赖里没有 Redis；代码与文档均注明"仅适用单实例"，多实例需换共享存储 |
| 8 | 研判在**事务外**调用 Dify，回写用 `WHERE id=? AND assessment_request_id=?` 条件更新 | 不占客户行锁；旧任务后返回会被自动废弃（有测试覆盖） |

## 五、端到端验收证据（真实 HTTP，2026-10-16）

启动 `uvicorn app.main:app --port 8000`，对云库 `education` 执行全链路：

| 步骤 | 接口 | 结果 |
|---|---|---|
| OpenAPI 契约 | — | M2 归属 **16 条全部注册**，缺失 0；总路由 91 条 |
| 公开项目 | API015 / API016 | 200；未发布项目 404；公开 DTO 不含 `admissionRules`/`defaultDeptId` |
| 公开活动 | API019 / API020 | 200；草稿活动 404；`remainingCapacity` 实时 |
| 建活动 | API021 / API022 | 201 DRAFT → PATCH 开放 → 200 OPEN，`remainingCapacity=2` |
| 访客客服 | API027 | 公开问答 200（带 3 条出处）；留资草稿 `CAPTURE_LEAD`；越界请求 `proposal=null` + `OUT_OF_SCOPE_REQUEST` |
| 确认留资 | API023 | 两次（表单 / 客服渠道）均 `{accepted:true,receiptNo}`，**结构完全一致**；库中同手机号**仅 1 条客户主档** |
| 报名 | API024 | 201 `REGISTERED`，返回一次性 `cancelToken`；名额 2 → 1 |
| 重复报名 | API024 | 409 `DUPLICATE_REGISTRATION` |
| 错误凭据取消 | API025 | 404 `NOT_FOUND`（不暴露报名是否存在） |
| 正确凭据取消 | API025 | 200 `CANCELLED`；名额 1 → 2（释放） |
| 研判 | API041 / API042 | 201 `SUCCEEDED`；报告逐项目 `decision`，缺 `language_level` → `NEEDS_INFO`，**`latestScore=null`** |
| 简历提取 | API096 | 200，`facts` 含 `education/language_level/date_of_birth`，`missingFields=[]`；**客户版本与研判状态未变** |
| 扫描件 | API096 | 422 `NO_READABLE_TEXT` |

> 复现：`cd backend && python -m uvicorn app.main:app --port 8000`，另开终端按上一节顺序调接口。
> 端到端脚本为一次性验收脚本，验收后已删除（不留在仓库）。
