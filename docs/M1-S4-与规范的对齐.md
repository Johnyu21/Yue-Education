## 五、注意事项

| ❌ 不要 | 为什么 | ✅ 应该 |
|---|---|---|
| 看规范文档对代码，以为对不上 | 差异已列在这里 | **以本文档为准**（代码是实际状态） |
| 按规范把 `controllers` 砍回 9 个 | 会撞车（organization 没地方放） | 先问 P1 |
| 不知道 `deploy/` 为什么存在 | 以为是多余的 | 见 2.2（云上部署用） |
| 自己建 `backend/sql/` 另放 schema | 两份 schema 会不一致 | **只改 `deploy/schema.sql`** |
