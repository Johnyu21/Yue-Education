# 一键运行粤教项目

## 日常操作

1. 双击桌面的“启动粤教项目.cmd”。
2. 等待窗口显示“项目已就绪”，浏览器会自动打开正式首页。点击首页“进入服务系统”即可登录。
3. 启动窗口可以关闭，前后端会继续运行。
4. 用完后双击桌面的“停止粤教项目.cmd”。

项目文件夹内也有“一键启动.cmd”和“一键停止.cmd”，作用相同。桌面文件指向当前正式项目；项目搬家后可直接使用新位置里的这两个文件。

## 当前使用地址

- 首页：http://127.0.0.1:5173/#/
- 登录：http://127.0.0.1:5173/#/login
- 后端：http://127.0.0.1:8000/
- 后端接口文档：http://127.0.0.1:8000/docs

启动脚本仅启动正式开发环境。之前的5174/8001独立演示实例已经停止；正式项目已具备那批测试账号。账号清单见[Dify配置与正式项目测试账号使用说明](Dify配置与正式项目测试账号使用说明.md)。

## 修改配置后的操作

修改backend/.env中的Dify URL、KEY或其他设置后，双击停止脚本，再双击启动脚本。已运行时再次双击启动会复用现有服务并打开网页，不会自动重载后端配置。

## 如果启动失败

启动窗口会保留错误提示。检查下面两个日志文件：

- backend/logs/local-backend.log：后端、数据库连接和配置错误。
- backend/logs/local-frontend.log：前端启动错误。

云端数据库需要网络可达，脚本会等待后端数据库就绪后再启动前端。端口被其他程序占用时会明确提示，不会自动改到另一个端口。

当前电脑的Python环境、Node.js和前端依赖已经具备；脚本直接使用backend/.venv，不需要手动激活虚拟环境。换电脑时需要先按项目说明安装相应环境和依赖。

## 实现和验证

启动和停止的辅助代码位于tools/local_project_runner.py、tools/frontend_dev_runner.cjs，运行状态与日志位于被Git忽略的backend/logs。停止时会核对进程身份、创建时间及本次运行标识，避免误停其他程序；优先通过停止标记正常关闭前后端。脚本不执行建表、迁移或测试资料初始化。

已经实测：正式前后端启动、数据库就绪、前端代理可用、重复启动复用进程、桌面入口启动并调用系统默认浏览器、停止后释放端口。初始5173/5174/8000/8001服务均已停止；完成脚本测试后再次停止，等待用户按需双击启动。
