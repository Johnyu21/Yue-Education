## 装配与认证

使用新增入口 app.m5_main:app 才会接入下面的实现。app.main:app 保持组员原状。

## 主要请求字段

### 保存日报

PUT 日期路径中的日期不再放进请求体；M5 独立 PUT 路径需要 report_date。

~~~json
{
  "original_text": "今天跟进了学生入学材料",
  "content": {
    "work_summary": "完成入学材料跟进",
    "items": [{"category":"ENROLLMENT","description":"跟进入学材料","student_ids":[],"source_event_id":null,"count":1,"result":"等待补件"}],
    "difficulties":"无",
    "next_plan":""
  },
  "expected_version": null
}
~~~

content 也接受 structured_content 别名。新增时 expected_version 省略或 null；更新必须使用最新 version。
category：CUSTOMER / DELIVERY / ENROLLMENT / PSYCH / COMPLAINT / LEAVE / OTHER。
学生 ID 必须在当前负责范围。来源事件 ID 为 P 加心理预警 ID，或 F 加投诉工单 ID；不能伪造或跨范围关联。
提交必须有工作总结和困难支持；没有困难填“无”，明日计划选填。

### 状态操作

提交、撤回、通过：{"expected_version":2}。
退回：{"expected_version":2,"reason":"请补充工作结果"}。
独立 action 路径额外包含 action：SUBMIT / WITHDRAW / APPROVE / RETURN。
主管不填写日报、不自审；普通员工不能审核。已通过日报修改后重新送审，统计继续使用最近通过的内容。
日报、报告 ID 使用 M5 新表的 UUID 字符串；不要当作原表的数字 ID。

### 报告预览

~~~json
{"type":"DAILY_WEEK","start_date":"2026-10-12","end_date":"2026-10-17","employee_user_ids":[]}
~~~

类型：CUSTOMER_OPERATION / DAILY_DAY / DAILY_WEEK / PSYCH_WEEK / COMPLAINT_WEEK / MANAGER_WEEK。
兼容旧类型 customer / daily / psych / complaint；daily 默认周汇总，日汇总请显式使用 DAILY_DAY。
日期不超过今天，跨度最多 366 天；日汇总的开始和结束日期相同。
主管默认本部门；其他员工默认本人。employee_user_ids 不能扩大本人权限。
心理周报：实际班级关系确认的班主任负责学生，或已授权主管的本部门；仍需正式项目 psych_access_enabled。
投诉周报仅限具有 can_handle_feedback 的部门主管。无权限类型从 capabilities 列表中省略。
返回 metrics / facts / narrative / warnings / ai_status。Dify 不可用时保留后端统计，ai_status=UNAVAILABLE。

### 保存与导出

POST reports：title、type、start_date、end_date、narrative，employee_user_ids 与预览保持一致。
新建不填 id；修改带 id 和 expected_version，不能改变类型、日期和员工范围。保存时重新核实指标，正文作为人工确认文本，ai_status=MANUAL。
主管周报保存后可单独提交；提交后不修改。Word、PDF 从已保存的报告导出。

### 报告助手

先 GET chat 取得 version，再 POST messages：message、UUID 格式 request_key、expected_version，可选 student_id、report_date。
返回 answer、draft、missing_fields、ai_status、version；必要信息齐全后仍需员工自行检查、保存、提交。
最后一次请求支持同键同内容重试返回；同键换内容报冲突。会话不直接写学生、客户或日报业务表。
数据问答目前覆盖新增客户、当前未签约意向人数；其他复杂提问需要下一轮扩展白名单。
用户请求生成报告时先返回类型和日期 proposal，供后续前端确认后调用预览接口。
